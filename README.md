# Pipeline de Captación Inmobiliaria Chile

Pipeline de datos end-to-end (ELT) en Google Cloud Platform. Extrae datos de arriendo de departamentos en la Región Metropolitana (Toctoc y PortalInmobiliario, 2023-2024) junto con la serie histórica de la UF, los carga crudos a BigQuery y los transforma con SQL por capas (staging → marts) para responder preguntas de mercado y captación de propietarios, visualizadas en un dashboard de Power BI.
